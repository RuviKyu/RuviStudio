HOW TO USE THIS FILE
  Find the CHANNELS line that names the channel from the packet's 00_README,
  take its SUFFIX, and append it VERBATIM to every AI-section prompt (PROMPT 1)
  and to every -ALTERNATIVE- prompt (|CHANNEL ART STYLE|). Keys below a SUFFIX
  are that channel's section rules (defaults in brackets):
  AI_TARGET_S     AI sections are cut to THIS length, on the strong pause nearest
                  the target [20]. PASS within ±AI_TOL_S, WARN within 5 s, FAIL beyond.
  AI_TOL_S        tolerance band around AI_TARGET_S [2]
  AI_MAX_S        hard ceiling for AI sections [25]
  MAX_SECTION_S   ceiling for HOOK / MAP / REF / CHAR sections [30]
  AI_PROMPTS      prompts per AI section [1]      ALT_PROMPTS  per special section [1]
  DESCRIPTION     the channel's YouTube description template (Phase D writes
                  [Subject]_description.txt from it; {…} fields are filled per title)

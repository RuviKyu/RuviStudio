TurboFlow bridge
How it works: in a title's prompts panel press copy missing (or copy all) — besides filling the clipboard the Studio records a batch: "TurboFlow's 001 = my 007, 002 = my 019 …". Paste into TurboFlow (Image mode, 16:9, x1 per prompt, numbered names starting at 001, download folder turboflow) and start it. As the files land in that folder they are moved into the title's AI Images\ under their real numbers; whatever TurboFlow fails to make stays missing — press copy missing again for the retry batch. No code of the extension is touched; it keeps running in your own Chrome with your own licence.
